# Política de seguridad

Este repositorio contiene la landing estática de DAC Alliance, alojada en GitHub Pages.
Es un sitio sin backend, sin formularios y sin datos de usuario: la superficie de ataque
real es acotada (ver auditoría interna para el detalle), pero valoramos cualquier reporte.

## Reportar una vulnerabilidad

Si encontrás un problema de seguridad (clonado del sitio con fines de phishing, una
cabecera mal configurada, una dependencia comprometida, o cualquier otro hallazgo),
escribinos a:

**contacto@dacalliance.com**

Incluí una descripción del problema, pasos para reproducirlo si aplica, y el impacto
potencial. Respondemos en un plazo razonable y coordinamos la corrección antes de
cualquier divulgación pública.

## Alcance

- Código fuente de este repositorio (`index.html`, `styles.css`, `app.js`, assets).
- Configuración de GitHub Pages y DNS asociados a este sitio.

No se ofrece recompensa económica por reportes (no hay programa de bug bounty).
